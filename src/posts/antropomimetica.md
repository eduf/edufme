A palavra **antropomimética** (imitar humanos) está circulando pela minha cabeça. É que, quando comentamos a IA, o foco vai para como os LLMs simulam a linguagem humana. Mas há outro comportamento deles que lembra um velho conhecido nosso: o cansaço. No caso do Claude Code, é chamado de [Degradação de Modelo](https://docs.bswen.com/blog/2026-05-29-ai-model-quality-degradation/). O desempenho cai conforme a conversa vai ficando mais longa e complexa — mesmo que ainda haja *tokens* disponíveis. Antropomimética involuntária? No post linkado acima, há algumas dicas para contornar essa "fadiga" de IA.
